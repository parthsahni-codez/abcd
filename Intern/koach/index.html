5-Day Curriculum

A structured, hands-on journey from setup to publication.

  • Set up Claude as your Research Assistant (Projects): system prompt, context, upload your own papers
  • Import your reference library (Mendeley Project via export/Drive)
  • Connect Consensus + Google Drive for live evidence
  • Cowork: delegate a full multi-step task - when to hand off vs chat
Outcome: A working Research Assistant loaded with your own library
  • Rigorous literature search + live reference verification (DOI/journal check, no hallucinated refs)
  • Extract findings with Elicit; free bibliometrics via OpenAlex in Colab
  • Build your conceptual framework figure + gap statement
Outcome: Verified mini-review + gap statement + framework figure

Taught as a workflow with a technique menu - 2-3 run live as exemplars, the rest handed over as ready-to-run assets.

  • Quant, live in Claude: cleaning, descriptives/inferentials, regression, mediation/moderation, EFA, clustering & latent profiles, meta-analysis, AHP, ISM
  • Quant, publish-standard in Colab: CFA (lavaan), PLS-SEM (seminr / SmartPLS)
  • Qual & NLP, live in Claude: thematic & content analysis, similitude, keyness, correspondence, word clouds; topic modelling (LDA/BERTopic), sentiment, text mining
  • Qual, publish-standard in Colab: Reinert lexical classes (rainette)
  • The boundary rule: self-contained Python runs live; external software/network Colab; verifying AI output
Outcome: Cleaned dataset + one quant + one qual/NLP result + reusable notebooks
  • Draft + reviewer-mode self-audit; response-to-reviewers letter
  • Final reference-verification pass before submission
  • AI-use disclosure (COPE/publisher rules) + OSF preregistration - your differentiator
  • Build your own reusable research Skill + capstone recap
Outcome: Audited section + disclosure statement + a personal custom Skill
